# Arctic-Ship-Navigation-

An advanced Arctic Ship Navigation & Route Optimization System featuring real-time marine routing, weather observations, and intelligent route monitoring.

## Features
- **Interactive Polar Map**: High-performance OpenLayers navigation map.
- **Route Optimization**: Real-time waypoint analysis and route evaluation.
- **Weather & Ice Conditions**: Live Open-Meteo weather integration and iceberg tracking.
- **Backend & WebSockets**: Node.js/Express backend with live WebSocket updates.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Running

1. **Backend Server**:
   ```bash
   cd backend
   npm install
   npm run dev
   ```
   Runs on `http://localhost:4000`.

2. **Frontend Application**:
   ```bash
   npm install
   npm run dev
   ```
   Runs on `http://localhost:5173`.
